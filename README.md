# Task Manager
This project is built in Vanilla JS + DOM Manipulations. It was made for the final project for Skillwill Front-End Course.

# What does the project represent
This project is merely a showcase, a template in a way. It represents that the developer can:
- Work with JavaScript.
- Is comfortable with DOM Manipulations.
- Can work with HTML/CSS and have the HTML be semantically correct.
- Is comfortable working with Local Storage and Session Storage.
- Can fetch data from an API and parse the data from it.

# How to preview it
You can preview the website by following the URL: https://nikoloz-code23.github.io/task-manager/

# How to build it
If you want to try work with the project, simply clone it:
```bash
# Clone with SSH
git clone git@github.com:nikoloz-code23/task-manager.git
# Or clone with HTTPS
git clone https://github.com/nikoloz-code23/task-manager.git
```
And run it with either `LiveServer` extension, or just open the `index.html` in your favorite web-browser.
